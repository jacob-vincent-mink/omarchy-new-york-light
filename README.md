# Omarchy New York Light

A light Omarchy theme for turn-of-the-century New York: a color Fifth Avenue, the harbor skyline, and the Statue of Liberty. Brick, cream, and pale sky shape the palette.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-new-york-light.git`, then run `omarchy theme set new-york-light`. Cycle the three wallpapers with `omarchy theme bg next`.

For the companion theme, see [Omarchy New York Dark](https://github.com/jacob-vincent-mink/omarchy-new-york-dark).

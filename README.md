# Omarchy New York Light

Fifth Avenue in 1900, with photochrom brick, cream, and pale sky.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-new-york-light.git`, then run `omarchy theme set new-york-light`.

For the companion theme, see [Omarchy New York Dark](https://github.com/jacob-vincent-mink/omarchy-new-york-dark).
